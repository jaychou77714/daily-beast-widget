# 小栗 1.0｜iPhone 桌面精神助理

獨立於《每日發病 Cloud》與《爆肝獸 4.0》的 **Scriptable 中型橫向 Widget**。

## 目前可用
- 米白色橫向 Widget：顯示「小栗」的當前問候、日期及頭像。
- 輕觸 Widget 開啟 Scriptable，**可使用鍵盤自由輸入訊息**；這是關鍵字＋原創台詞的免費規則式聊天，**不是 GPT 或真正的 AI 語言理解**。
- 訊息與近期話題（工作、遊戲、心情、睡眠、家庭）儲存在 iPhone 本機，之後可以問你先前提過的事。
- 直接從 iPhone **照片 App 選取你提供的女生圖**，程式裁成方形頭像；**不會將照片公開上傳 GitHub**。
- 主動關心通知是**使用者選擇開啟**，每天約 12:30、20:30。關閉會取消小栗自己的待發通知，不影響其他 Scriptable 設定。
- GitHub 的 `companion/public-lines.json` 只放公開原創問候台詞，不包含任何聊天記憶。
- 可查看／清除自己的聊天記憶。

## 一次安裝步驟（iPhone）
1. 在 Safari 點開 [小栗_桌面精神助理1.0.js](../scriptable/小栗_桌面精神助理1.0.js) → **Raw** → 複製完整程式碼。
2. 開啟 Scriptable → **＋** 新增腳本 → 貼上 → 命名 **小栗精神助理**。
3. 在 Scriptable 直接按 ▶，進入小栗的操作選單。
4. 選 **「選小栗的照片」**，從 iPhone 相簿選擇你傳給 ChatGPT 的那張棕色妹妹頭女孩圖。程式只保存裁切頭像在本機。
5. 選 **「打字跟小栗聊天」**，輸入一段文字並傳送，確認小栗有回應。之後可自己決定是否開啟每天兩次問候。
6. 在桌面新增一個 **Scriptable 中型 Widget**，長按 → 編輯 Widget → Script 選 **小栗精神助理**。不要把原有兩張小工具移除，除非你想替換其中一張。

## 技術與隱私
- Scriptable 本機路徑：`FileManager.local().documentsDirectory()/xiaoli-companion/`。
- 本機檔：`memory-v1.json`（最多最近 60 則訊息）、`xiaoli-avatar.png`（相簿裁切照）、`public-cache.json`（公開問候快取）。
- **聊天內容不會送到 GitHub，也不會呼叫外部 AI API**。因為是規則式聊天，無法像 ChatGPT 一樣自由深入回答所有問題。
- GitHub 只有公共設定與程式；公開儲存庫不適合存放個人聊天、原始照片或 API 金鑰。
- iOS Widget 不支援直接彈出鍵盤文字輸入；點擊會跳進 Scriptable。小栗的問候換字依賴 iOS Widget 的系統更新時機，不能保證精準。
- 本機資料不等於跨裝置同步或永久備份；刪除 Scriptable 或更換手機時，需要另外備份。
- 通知每日固定兩次，並非即時監聽你正在做什麼，也不會在背景自動讀取你的手機行為。
