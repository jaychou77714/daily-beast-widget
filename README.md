# 每日發病｜原創漫畫情緒急救站

**目前主要專案：iPhone 網頁 App（不使用 Scriptable）**

這是一個給疲憊大人的漫畫放鬆空間，不顯示日期，無需每日簽到。

## 網頁 App（A＋B＋C＋F）

- **A 情緒急救漫畫室**：按當下心情隨機看原創漫畫。
- **B 厭世扭蛋機**：免費抽幽默台詞與漫畫，包含純娛樂 SSR 彩蛋。
- **C 吐槽垃圾桶**：本機規則式趣味回應，不會儲存或上傳輸入文字。
- **F 私藏發病圖鑑**：分類、搜尋、收藏、分享。
- **20 篇精繪漫畫**（16 篇重繪、4 篇新故事），另有 **125 則原創幹話**；可增加新的漫畫圖片。
- 支援 iPhone 加入主畫面、基本離線閱讀，不需要 Scriptable。
