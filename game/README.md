# 爆肝獸 4.0 · 場外生存日誌

這是放在 **iPhone 下方中型 Scriptable Widget** 的養成 RPG。上方《每日發病 FINAL Cloud》維持原狀。

## 已完成
- **每日事件二選一**：24 個原創故事；每天選一次，獲得經驗值、獸幣、活力與怨念變化。
- **每日免費抽卡**：20 張原創人生卡；N 75%、R 20%、SSR 5%，一天一次，不花錢。
- **四條進化**：社畜、宅獸、窮鬼、擺爛；Lv.5 與 Lv.10 解鎖進化稱號。
- **角色卡和成就圖鑑**：看經驗、成就及四條路線的累積分數。
- **本機存檔**：保存在 iPhone Scriptable 本機的 `beast4-save.json`，並自動保留 `beast4-save-backup.json`。
- **不逼打卡**：幾天不開也不會死；斷網時有內建劇情可玩。
- **沿用原本四張 PNG**：路線切換角色動作，升級改變稱號；各進化階級的全新獨立角色圖仍待美術製作。

## iPhone 安裝步驟
1. **保留**原本的 `鄉民今日發病3` 和 `Scriptable/爆肝獸/` 四張 PNG，當備份。
2. 點開 [4.0 完整程式](../scriptable/鄉民今日發病_爆肝獸4.0.js)，按 **Raw** 複製全部。
3. 開啟 Scriptable → 按 **＋** 新增 → 貼上程式碼 → 命名 **鄉民今日發病4**。
4. 直接按 ▶，應顯示**《爆肝獸：場外生存日誌》**互動選單。試玩每日事件、抽人生卡，並可選預覽 Widget。
5. 桌面長按**下方中型 Widget** → **編輯小工具** → Script 選 **鄉民今日發病4**。
6. 點桌面 Widget 即會開啟 Scriptable 遊戲選單。上方漫畫日曆不用改。

## GitHub 內容
- `game/game-data.json`：24 事件＋20 張卡。
- `game/today.json`：當日指定事件 ID。
- `scripts/generate-game.mjs`：每日事件排程生成程式。
- `.github/workflows/daily.yml`：同時更新 3.0 原始幹話與 4.0 養成事件。
- `scriptable/鄉民今日發病_爆肝獸4.0.js`：完整遊戲程式。

## 重要限制
- 目前事件、卡片、幹話均為**原創**，沒有接上巴哈場外即時資料，也未付費使用 AI API。
- 個人存檔**不會上傳公開 GitHub**。刪除 Scriptable 或清理本機資料前，務必備份。
- GitHub 排程可能延遲；iOS 也不保證準點更新。日期變化時，離線仍能自動挑新事件。
- **2026-11-20 至 2027-02-18** 為目前設定的 90 天每日發布試行期。停止發布不等於自動撤銷 GitHub 授權。
- 目前以既有四張角色動作搭配進化稱號；未生成額外進化 PNG。
