ABOUT THIS LITTLE PLACE

每日發病是什麼？

這是一間給疲憊大人的漫畫避難所。不需要連續簽到、不必填心情報表，也不用假裝正能量。

所有趣味漫畫和幹話均是原創內容。吐槽輸入不會送出；收藏存在這台裝置。沒有追蹤分析、帳號註冊或付費扭蛋。

加入 iPhone 主畫面：Safari 按「分享」→「加入主畫面」，之後就能像 App 一樣打開。

初始漫畫庫為網頁新作；原先 iPhone Scriptable 的 70 張本機漫畫尚未匯入網站。後續 GitHub 發布的新作會自動加入。
