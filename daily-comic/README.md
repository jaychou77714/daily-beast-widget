# 上方《每日發病 FINAL Cloud》— GitHub 雲端串接

這支 Scriptable **大型 Widget** 是原本《每日發病 FINAL》的相容升級，不是下方《鄉民今日發病3》的腳本。

## 已完成
- 日期、農曆、節慶及漫畫排版與既有 FINAL 相同。
- 使用 iPhone 本地 `Scriptable/DailyComicFINAL/` 的 365 則原文案、60 張日常漫畫、10 張節慶漫畫與 2027 年假日資料，**不重新上傳這些大型圖片**。
- 額外從 GitHub `daily-comic/cloud-overrides.json` 讀取**指定日期**的新標題、短句與對應漫畫 scene 編號；沒有雲端資料時照常使用本地原版。
- **台灣節慶優先**；雲端設定不會改寫現有節慶內容。
- 2026/11/20、11/21 放了兩個配對場景的新句子供實機驗證。
- 雲端資料讀不到時仍離線可用。iOS 更新時間由系統安排，不保證剛過 00:00 立即切換。

## iPhone 升級
1. **不要刪除**原本 `每日發病_FINAL` 和 `DailyComicFINAL` 資料夾（70 張漫畫與 JSON 全都保留）。
2. 手機 Safari 開啟 [每日發病_FINAL_Cloud.js](../scriptable/每日發病_FINAL_Cloud.js)，按 **Raw**，全選複製。
3. Scriptable → 右上角 **＋** → 貼上 → 命名 **每日發病 Cloud** → 按 ▶，確認仍看到原本的漫畫版面。
4. 桌面長按**上方大型** Scriptable Widget → 編輯小工具 → 腳本選 **每日發病 Cloud**。
5. 下方「鄉民今日發病3」完全不必變更。

## GitHub 雲端如何新增自己的漫畫幹話
編輯 [cloud-overrides.json](cloud-overrides.json) 的 `date_overrides` 區塊，例如：

```json
{
  "2026-11-20": {
    "title": "刷卡的超能力",
    "punch": "付款只要一秒，後悔可以分十二期。",
    "scene": 45
  }
}
```

其中 `scene` 必須是 1～60 的既有漫畫場景，且文案與漫畫主題相符。
之後 Widget 在重新整理時便會取得新內容；**不會自動從巴哈姆特收集或生成新句子**。

## 設計上的界線
- GitHub 是雲端內容庫，**不是即時 AI**。內容要新增、審核或另行接寫作自動化，才會有真正的新篇章。
- 2027 假日按已下載的資料表運作；日後新增年度時必須更新本地假日資料，這份新版不會替未確認的日期標示「國定假日」。
- 此儲存庫公開，禁止上傳私人身分、工作機密、API Token 或心情日誌。
